# nnU-Net Inference (Prediction) Guide
This guide provides the commands required to run inference (generate segmentation masks) using your trained nnU-Net models on the server.

---

## What is the output?
The output generated by the predictor is a **segmentation mask** saved as a compressed NIfTI image (`.nii.gz`).
Since we updated the dataset setup to combine labels, the output files will contain the following label values for each voxel:
* **`0`**: Background
* **`1`**: Tumor Core (necrosis + enhancing tumor)
* **`2`**: Edema

---

## 1. Prepare Your Input Data
nnU-Net expects your test/input scans to be placed in a single input folder. 
* All modalities for a single patient must have the correct channel suffixes (`_0000`, `_0001`, `_0002`, etc.) and the same name prefix.
* For example, for patient `100101A` using the 2-channel model (FLAIR + T1post):
  * `100101A_0000.nii.gz` (FLAIR)
  * `100101A_0001.nii.gz` (T1post)
* File names and suffixes must match what was used during training.

---

## 2. Running Inference

By default, `nnUNetv2_predict` will check your model results directory, automatically load all 5 folds (`fold_0` to `fold_4`), run predictions through all 5 models, and **average (ensemble) the softmax probabilities** to generate the final segmentation. This 5-fold ensemble is highly recommended for maximum accuracy.

### Option A: Standard 3D Full-Resolution 5-Fold Ensemble (Recommended)
This uses the standard `3d_fullres` model ensembled across all 5 folds on a GPU:

```bash
docker run --runtime=nvidia -it --rm \
  -v /mnt/local/data/rainsun/metastases/IDIA-BrainMetastases-main/train/nnUNet_rain/nnUnet_dataset:/workspace/nnunet_data \
  -v /path/to/server/input_scans:/workspace/input \
  -v /path/to/server/output_predictions:/workspace/output \
  nnunet-rain "nnUNetv2_predict -i /workspace/input -o /workspace/output -d 1 -c 3d_fullres"
```
*(Replace `/path/to/server/input_scans` and `/path/to/server/output_predictions` with your actual directory paths on the server).*

---

### Option B: Standard 2D Model 5-Fold Ensemble
If you trained the `2d` configuration and want to generate predictions:

```bash
docker run --runtime=nvidia -it --rm \
  -v /mnt/local/data/rainsun/metastases/IDIA-BrainMetastases-main/train/nnUNet_rain/nnUnet_dataset:/workspace/nnunet_data \
  -v /path/to/server/input_scans:/workspace/input \
  -v /path/to/server/output_predictions:/workspace/output \
  nnunet-rain "nnUNetv2_predict -i /workspace/input -o /workspace/output -d 1 -c 2d"
```

---

### Option C: Single Fold Inference (e.g. Fold 0 only)
If you only trained Fold 0 (or want to test a single model quickly), specify the fold using the `-f` flag:

```bash
docker run --runtime=nvidia -it --rm \
  -v /mnt/local/data/rainsun/metastases/IDIA-BrainMetastases-main/train/nnUNet_rain/nnUnet_dataset:/workspace/nnunet_data \
  -v /path/to/server/input_scans:/workspace/input \
  -v /path/to/server/output_predictions:/workspace/output \
  nnunet-rain "nnUNetv2_predict -i /workspace/input -o /workspace/output -d 1 -c 3d_fullres -f 0"
```

---

### Option D: Custom Residual Encoder Plan or Trainer
If you trained using the Residual Encoder plan and a custom trainer (like `nnUNetTrainerMets`), you must specify them in the command using `-p` and `-tr`:

```bash
docker run --runtime=nvidia -it --rm \
  -v /mnt/local/data/rainsun/metastases/IDIA-BrainMetastases-main/train/nnUNet_rain/nnUnet_dataset:/workspace/nnunet_data \
  -v /mnt/local/data/rainsun/metastases/IDIA-BrainMetastases-main/train/nnUNet_rain:/opt/nnunet \
  -v /path/to/server/input_scans:/workspace/input \
  -v /path/to/server/output_predictions:/workspace/output \
  nnunet-rain "nnUNetv2_predict -i /workspace/input -o /workspace/output -d 1 -c 3d_fullres -p nnUNetResEncUNetLPlans_custom_0624 -tr nnUNetTrainerMets"
```

---

## 3. How to View the Segmentation Outputs
Once prediction finishes, your output folder on the server will contain `.nii.gz` files with the same names as the input scans (e.g., `100101A.nii.gz`).

To visualize the predicted labels overlayed on the structural scans:
1. **Download the files** to your local machine (including the raw T1post/FLAIR scan and the output `.nii.gz` segmentation mask).
2. Open them in a medical image viewer:
   * **ITK-SNAP (Recommended):**
     1. Open the structural image (e.g., `100101A_0002.nii.gz` [T1post]) as the main image.
     2. Go to **File -> Load Segmentation** and select your output file `100101A.nii.gz`.
     3. You will see the labels (Tumor Core as Label 1, Edema as Label 2) overlayed on the scan.
   * **3D Slicer:**
     1. Drag and drop both the T1post image and the segmentation mask into the workspace.
     2. Set the segmentation mask volume as an overlay using the **Segmentations** module.
